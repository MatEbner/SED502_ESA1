# Fotografie-Portfolio

Eine kleine statische Portfolio- und Galerieseite für Fotografien. Besucherinnen und Besucher können Bilder ansehen und die Galerie später nach Motiv filtern.

## Projekt

Die Website wird mit Vite und TypeScript umgesetzt. Sie verwendet semantisches HTML und rendert die Fotokarten dynamisch aus einem TypeScript-Datenarray. Die Filterbedienung soll über Event Delegation umgesetzt werden. Fotos werden lokal im Ordner `public/images/` gespeichert.

## Entwicklung

```bash
npm install
npm run dev
```
